# Starter Web Project

This is a minimal Spring Boot application that displays a simple "Hello, World" message.

## Requirements

- Java 17 or later
- Gradle 8+

## Running the application

If this project was cloned without the Gradle wrapper JAR, generate it first:

```bash
gradle wrapper
```

Then start the server:

```bash
./gradlew bootRun
```

Once started, open your browser and visit [http://localhost:8080](http://localhost:8080) to see the message.

## Running tests

```bash
./gradlew test
```
